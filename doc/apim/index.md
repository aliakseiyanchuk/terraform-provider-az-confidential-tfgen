# `apim` group

This group contains resources configuring the resources related to API Management service Azure provider.

```shell
tfgen apim help
```

The command above would print:
```
Usage: tfgen [<standard options>] generic <subcommand> [<args>]
Possible sub-commands are:
- named_value
- subscription
```

The group has the following resources:
- `named_value` to create a named value within APIM service, and
- `subscripion` to create a subscription to APIs with pre-selected primary and secondary subscription keys
